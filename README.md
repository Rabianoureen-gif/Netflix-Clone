#  Netflix Clone

A responsive frontend clone of the Netflix landing page built using HTML5 and CSS3.

##  Features

- **Hero Section:** Custom header layout with background image and call-to-action buttons.
- **Responsive Layout:** Works smoothly across desktop and mobile screens.
- **FAQ Section:** Cleanly structured collapsible / styled accordion layout for frequently asked questions.
- **Custom Styling:** Pure CSS styling for buttons, cards, and input fields.

##  Tech Stack

- **HTML5**
- **CSS3**
- **Git & GitHub** (Version Control)
